## 1. Cách mở và trình chiếu

- Mở file [`index.html`](index.html) trực tiếp bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari).
- **Phím tắt điều khiển:**
  - `Phím mũi tên phải` / `Phím Space` / `Page Down`: Chuyển sang slide kế tiếp.
  - `Phím mũi tên trái` / `Page Up` / `Backspace`: Quay lại slide trước.
  - `F`: Bật / tắt chế độ toàn màn hình (Fullscreen).
  - `Home` / `End`: Về slide đầu / slide cuối.
  - Nhấp chuột vào 25% mép trái/phải màn hình để lật slide.
